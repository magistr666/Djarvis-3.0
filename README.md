# Djarvis 3.0 — голосовой ассистент

Голосовой мост на базе Vosk (STT) + edge_tts (TTS) с 3D-аватаром. Wake-слово **«Джарвис»**. Умеет выполнять команды локально и передавать сложные запросы в MultiTool.

## Возможности

### Локальные навыки (без интернета)
- **Время и дата**: «который час», «какое сегодня число»
- **Анекдоты и сказки**: «расскажи анекдот» / «расскажи сказку»
- **Погода** (бесключевой wttr.in): «какая погода в Москве»
- **Открытие папок**: «открой документы», «мой компьютер», «загрузки», «рабочий стол», «корзина», «открой папку C:\...»
- **Открытие сайтов**: «открой ютуб», «вк», «яндекс» и др.
- **Запуск программ**: «открой блокнот», «калькулятор» и др.
- **Поиск файла**: «найди файл отчёт» (ищет в стандартных папках)
- **Калькулятор**: «сколько будет два плюс три»
- **Заметки**: «запиши ...» (сохраняет в `заметки.txt`)
- **Управление системой**: громкость, выключение/перезагрузка ПК, экран вкл/выкл
- «Джарвис, стоп» — выход

### Связь с MultiTool
Команды, не распознанные локально, отправляются в окно MultiTool; ответ читается OCR-ом с экрана и озвучивается.

## Установка и запуск

### Из исходного кода (Python 3.12)
```bat
pip install vosk sounddevice pyautogui pygetwindow pyperclip edge-tts numpy
```
Модель Vosk (`vosk-model-small-ru-0.22`) должна лежать в
`C:\Users\<ПОЛЬЗОВАТЕЛЬ>\AppData\Local\Temp\gigatool\vosk-model\vosk-model-small-ru-0.22`
(либо поправить `MODEL_DIR` в `jarvis_bridge.py`).

Запуск:
```bat
python jarvis_bridge.py
```

### Готовый сборщик (exe)
`dist\Jarvis.exe` — автономный one-file исполняемый файл (модель Vosk упакована внутри). Запускается из любого места, рантайм-файлы (`jarvis_state.json`, `jarvis_speech.json`, `заметки.txt`) создаются рядом с exe.

## Сборка exe из исходников
```bat
python -m PyInstaller --noconfirm --clean jarvis.spec
```

## Структура
| Файл | Назначение |
|------|-----------|
| `jarvis_bridge.py` | Основной мост: wake-word, STT, навыки, TTS |
| `jarvis_avatar.py` | Локальный HTTP-сервер оболочки/состояния аватара |
| `jarvis_avatar.html` / `jarvis_avatar_3d.html` | Web-оболочки аватара (Edge app-mode) |
| `three147.min.js` + `GLTFLoader147.js` + `robot.glb` | 3D-модель RobotExpressive |
| `jarvis.spec` | Конфигурация PyInstaller |

> **Примечание по юрисдикции:** ассистент работает для пользователей в Российской Федерации и не обходит блокировки ресурсов, недоступных в РФ.
